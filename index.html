Projects

RIID — Runtime-Independent Image Downloader

Research project at HSE Saint Petersburg: a Java utility that decouples P2P container image distribution (via Dragonfly) from the container engine, so any OCI-compatible runtime (Docker, Podman, Porto) can pull images without engine-specific integration. Verified against 100+ real images (2 KB–4.8 GB) with SHA-256 integrity checks and cluster benchmarks showing a 15–20% download-time improvement at 10 nodes.

PRAssign

Go + Gin microservice built for an Avito test task: manages users, teams, and pull-request assignment workflows with token-based auth, admin/author authorization, and aggregated statistics. Includes a Kafka-backed factorial pipeline that talks to the companion AsyncFactorial service, nginx load-balancing across replicas, and Docker Compose setups for integration, load (k6), and resilience testing.

AsyncFactorial

Scala service (cats-effect 3, fs2, fs2-kafka) for concurrent factorial processing in three modes: a Kafka consumer/producer paired with PRAssign, a Tapir-based HTTP API, and a console mode that runs tasks concurrently on cats-effect fibers and writes results asynchronously.

SmartCalendar / TimeTamer

"TimeTamer" is an Android productivity app (Jetpack Compose) with collaborative events, streaks/achievements, and AI-assisted task suggestions, backed by this JWT-secured Java/Kotlin server handling users, shared event invitations, and statistics.

Voevoda

A single-player top-down RTS built in Unreal Engine 4 (C++): command a general on a 2D map, fight AI-controlled generals, and reinforce your army from cities, with terrain/unit-type combat modifiers and a dynamic fog-of-war system with scouting units.

QA Test Task

An automated-testing and performance-audit suite for a web application: JUnit 5 and property-based (jqwik) tests, Jazzer fuzzing that surfaced real crash payloads, and Gatling load scenarios (baseline, spike, heavy) with GC/socket diagnostics, reported via Allure and JaCoCo coverage.
